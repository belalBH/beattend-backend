# CrystalHR - Premium Fintech HR Dashboard Mobile App

This project is a premium Flutter mobile application for HR management, featuring biometric attendance check-ins, presence tracking, meeting scheduling, and AI-powered sentiment analysis.

## Features

- **Mesh Background & Glassmorphic UI**: High-end visual experience tailored for executive usage.
- **Biometric Check-In System**: Tap-to-check-in biometric orb with support for Fingerprint, NFC, and Manual override simulation.
- **Time Matrix & Stats**: Track weekly completed hours against target hours with weekday presence visualizers.
- **Next Engagements**: View, schedule, and cancel calendar events and portfolio sync meetings.
- **HR Requests Ledger**: Multi-type request system for Leaves, Loans, Overtime, Deputations, and Salary Certificates.
- **Attendance Calendar**: Monthly interactive board with retroactive log insertions and status tracking.
- **Reports & Exporting**: pacing scores, analytical cards, grouped daily logs, and printable receipts.
- **AI Sentiment Analysis**: Executive advisory dashboard powered by server-side or local AI analytics synthesis.

## Run Locally

**Prerequisites:** Flutter SDK installed, configured, and a simulator or connected physical device.

1. Navigate to the project directory:
   ```bash
   cd crystal_hr
   ```
2. Get dependencies:
   ```bash
   flutter pub get
   ```
3. Run the app:
   ```bash
   flutter run
   ```
